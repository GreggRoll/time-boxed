# Contributing to Time Boxed

Everyone is welcome to help build Time Boxed. You can contribute bug fixes, features, accessibility improvements, design, documentation, or tests. First-time contributors are welcome, too.

## Free lifetime Pro for a merged contribution

When your pull request is reviewed, accepted, and merged by a maintainer, you will receive a **free lifetime subscription to Time Boxed Pro**. This means lifetime Pro access with no recurring subscription payment.

GitHub calls merge requests (MRs) **pull requests (PRs)**. The reward is for a successfully merged contribution; opening a PR or reporting an issue alone does not qualify.

After your PR is merged, comment on that PR to request your lifetime Pro reward. A maintainer will coordinate the redemption details with you. Do not post payment information, Apple account details, or other personal information in a public issue or PR.

## How to help

1. Browse the [issues](https://github.com/GreggRoll/time-boxed/issues), or open one describing the bug or improvement. For a larger change, discuss the idea first so we can agree on its scope.
2. Fork the repository and create a branch for your change.
3. Follow the [README build instructions](README.md#build-and-explore). Native iOS is the current development focus; the repository also includes the original web prototype and the static demo.
4. Keep the change focused. Check the behavior you changed and run relevant tests. For documentation or demo changes, check links and review the rendered page.
5. Open a pull request explaining the problem, your solution, and how you checked it. Include screenshots for visual changes and link any related issue.
6. Respond to review feedback. Once a maintainer merges your PR, you can claim your lifetime Pro reward.

You can also help by reporting bugs, suggesting improvements, and sharing feedback through the issue tracker.

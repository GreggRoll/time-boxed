# Public Apple trust roots

These DER certificates were downloaded from Apple's [Root Certificate Authority page](https://www.apple.com/certificateauthority/) on October 19, 2026:

- `AppleRootCA-G2.cer`
- `AppleRootCA-G3.cer`

They establish trust for the App Store's signed transaction data. They contain public certificates, not private keys. Renew them from Apple's published source when Apple updates its trust roots.
